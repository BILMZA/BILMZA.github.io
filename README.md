# BILMZA Portfolio

Static HTML portfolio for Muhammad Bilal Hamza, built with HTML, CSS, and JavaScript.

## Recommended repository name

For a personal portfolio, use:

```text
BILMZA.github.io
```

This publishes the site at:

```text
https://BILMZA.github.io/
```

If you prefer a project repository instead, use `portfolio`. The published URL will then be:

```text
https://BILMZA.github.io/portfolio/
```

The site uses relative local paths, so `index.html` and `cv.pdf` work with either URL.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static web server. No build step or package installation is required.

## Publish with GitHub Pages

1. Create a new public repository on GitHub named `BILMZA.github.io` (recommended) or `portfolio`.
2. Keep `index.html` and `cv.pdf` in the repository root.
3. Upload the project files, including `README.md`.
4. Open the repository on GitHub and select **Settings**.
5. Select **Pages** in the left sidebar under **Code and automation**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select the `main` branch and the `/ (root)` folder, then click **Save**.
8. Wait for the GitHub Pages workflow to finish. GitHub will show the published URL in the Pages settings.
9. Open the URL in a private/incognito window and verify the navigation, filters, external links, and CV download.

Changes pushed to the selected branch will be published automatically. The first deployment can take a few minutes.
